# GeoPostcodes Ranking — design direction

Status: Draft

## Character

GeoPostcodes Ranking has a dark-only, simple, and playful interface. It should feel like a friendly company pool ladder rather than administrative business software.

The visual hierarchy should emphasize:

1. the current ranking;
2. recent rating movement;
3. fast game registration;
4. recent results.

## Principles

- Dark mode is the only initial color scheme; no theme switcher is required.
- Use one lively accent color and restrained status colors against neutral dark surfaces.
- Avatars and concise, informal copy provide most of the personality.
- Prefer generous touch targets and a responsive single-column layout on phones.
- Keep tables readable on desktop while adapting ranking and result rows into cards on narrow screens.
- Avoid dashboards crowded with statistics, heavy animation, gradients everywhere, or game-themed visual clutter.
- Administrative controls remain visually secondary to everyday ranking and game actions.

## Initial screen set

- Magic-link sign-in and registration
- Ranking
- Register a game
- Game history
- Profile settings
- Administration: players, games, administrators, domain whitelist, and audit log

Detailed colors, typography, component styling, branding, and avatar art direction remain to be chosen.
